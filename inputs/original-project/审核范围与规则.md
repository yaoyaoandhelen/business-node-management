# 机器内容审核范围（产品方案）

本方案用于接入登记提交前的内容安全审核。当前原型使用“敏感词测试”等安全标记模拟结果，没有调用真实模型，也不解析附件。以下为拟接入后端的审核范围与规则，并非现有模型能力声明。

| 范围 | 字段 / 材料 | 检查方式 |
| --- | --- | --- |
| 业务自由文本 | 登记名称、运营机构名称、所属组织名称、物理地址、业务简介、证明材料文件名、备注 | 敏感词策略与上下文语义审核；主体名称、地址须结合业务语境，不能单字误杀 |
| 上传材料 | 核心业务证明材料、营业执照、法人身份证、服务承诺书 | 对文档提取正文、图片OCR提取文字；图片本身做色情与暴力图像识别；个人信息展示脱敏 |
| 结构化字段 | 服务类型、版本号、经营时间、统一社会信用代码、法人姓名、联系方式、身份证号、地址类型、服务地址、API地址 | 枚举、格式、长度、日期及HTTPS规则校验；不将身份证号/姓名作为敏感词直接拦截 |
| 地址安全 | 服务地址、API地址 | URL格式及域名安全策略可单独校验；不在提交时任意抓取链接正文，若要审核链接内容需另行确认范围 |

## “敏感词”包含哪些

不是“出现某个字就不通过”，而是根据语境、词库和策略确定的风险内容。建议的分类如下，最终词库和阈值须由业务方审核确定：

| 类别 | 典型内容 | 不应简单误判的情况 |
| --- | --- | --- |
| 色情、低俗 | 色情服务招揽、露骨色情描述、以性内容为目的的引流 | 正常医学、健康教育、防治宣传 |
| 暴力、威胁 | 针对个人的伤害威胁、煽动伤害、传播实施暴力的方法 | 安全培训、事故处置、新闻客观描述 |
| 辱骂、仇恨 | 针对个人的严重辱骂、针对群体的仇恨与歧视煽动 | 正常机构名称、历史材料引用 |
| 欺诈、非法招揽 | 诈骗诱导、假证件或非法交易招揽 | 反诈宣传、合法业务描述 |

业务禁用词（如夸大宣传、禁止经营的业务表述）另建可维护词库，不把正常行业术语纳入通用敏感词。原型中的“敏感词测试”是安全测试标记，不能直接作为生产词库。

## 审核结果规则

1. 先做必填与格式校验，再进行内容安全审核。
2. 明确命中高风险内容时，显示类型、字段/文件位置、适度脱敏的证据和修改建议，阻止申请进入人工审核。
3. 模型无法判定、文件无法解析、OCR失败或服务异常时显示“审核未完成”；保留草稿并支持重试，不能当作通过或敏感词命中。
4. 修改字段或替换材料后重新审核；后端校验结果与当前内容版本一致，防止审核旧内容、提交新内容。
5. 全部通过才创建待人工审核记录；机器通过不代表最终人工审核通过。
6. 生产结果由后端产生，不能信任前端场景开关或仅用前端关键词匹配。
